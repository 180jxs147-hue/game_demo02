# 章节资源命名与验收规范

## 命名规则
- 关卡资源：
  - 使用 `Resources/Levels/<level_id>.tres`
  - 例如：`1_2_5.tres`、`2_1_3.tres`
- 战前剧情：
  - 默认使用 `Dialogues/<level_id>.dialogue`
  - 若该关是特殊侧线入口，可使用 `Dialogues/<level_id>_start.dialogue`
- 战后剧情：
  - 若确实需要额外结尾文本，可使用 `Dialogues/<level_id>_victory.dialogue`
  - 仅用于特殊剧情，不作为默认必需资源

## 页面与流程规则
- 主流程默认链路：
  - `MainMenu -> SaveSlots/New or Load -> Battle -> PostBattleReport -> PostBattleRewards -> PostBattleRoute`
- 剧情播发规则：
  - 页面脚本优先通过 `GameState.play_level_intro_or_start(level_id, state)` 处理
  - 不在页面内手写新的剧情资源路径拼接
- 营地插入规则：
  - 对话中若需要先整备再开战，统一使用 `do enter_camp_before_level("<level_id>")`
  - 营地本身不负责决定剧情是否播放，只负责整备与出征

## 新关卡最低交付清单
- 一个 `LevelConfig` 资源
- 一个入口剧情，或明确确认该关无入口剧情
- 一个奖励池 ID
- 一个商店池 ID
- 可从战后页继续推进或返回营地
- 可在 `LevelSelect` 中显示

## 验收清单
- 资源验收：
  - `Resources/Levels/<level_id>.tres` 存在
  - `Dialogues/<level_id>.dialogue` 或 `Dialogues/<level_id>_start.dialogue` 存在
  - `EnemyLevels.tres` 已挂入该关卡
- 页面验收：
  - `LevelSelect` 可见该关
  - 战后页能正确显示下一关或章节结束信息
  - `CampShop` 能在需要时承接下一关
- 流程验收：
  - 可从主菜单进入该关
  - 可从剧情进入该关
  - 胜利与失败后都不会丢失导航上下文

## 近期约定
- 黄巾主线与后续章节继续沿用现有 `GameState` 导航桥接，不新增新的全局流程管理器。
- `Barracks` 必须保持图鉴定位，不承担局内军营功能。
- `CampShop` 保持轻整备页，不扩成重型经营基地。
